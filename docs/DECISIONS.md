### D-02: تحليل مدير الحزم (بلا تثبيت)
**حقائق البيئة (فحص قراءة فقط):**
- `python3` على المسار = Homebrew 3.15.2، و `venv` و `ensurepip` يعملان.
- يوجد أيضًا `/usr/bin/python3.12` (3.12.3)، لكن **بلا `ensurepip`**: حزمة `python3.12-venv` غير مثبتة، فلا يمكن إنشاء venv منه حاليًا.
- `uv` و `pipx` و Poetry غير مثبتة.
- PyYAML غير موجود في Python 3.15 (موجود فقط كحزمة نظام لـ 3.12)، أي أن YAML يحتاج اعتمادية.

| المعيار | uv | venv + pip | Poetry |
|---|---|---|---|
| ملف قفل قابل لإعادة الإنتاج | ✅ `uv.lock` | ❌ (يحتاج pip-tools) | ✅ |
| تثبيت Python 3.12 معزول للاختبار | ✅ يدير الإصدارات | ❌ يحتاج `apt install python3.12-venv` (sudo) | ❌ |
| يتطلب تثبيت أداة جديدة | نعم (ملف ثنائي واحد) | لا مع 3.15، نعم مع 3.12 | نعم |
| معياري (PEP 621) | ✅ | ✅ | جزئي (أقسام خاصة) |
| تثبيت المستخدم النهائي (P6) | `uv tool install` | `pipx` / `pip` | — |

**التوصية:** `pyproject.toml` معياري (PEP 621) كمصدر وحيد، مع **uv** للتطوير، لأنه يعطي ملف قفل ويسمح باختبار 3.12 و 3.15 دون sudo. يبقى المشروع قابلًا للتثبيت بـ `pip` عاديًا كمسار احتياطي موثق. **لن يُثبَّت شيء قبل موافقتك.**
