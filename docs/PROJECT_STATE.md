## 2. القرارات المؤكدة والمعتمدة (Confirmed Decisions)

1. **الاسم والهوية:** SIFR كاسم عمل مؤقت، والاسم الوصفي الداخلي AI Engineering OS.
2. **استقلالية النواة:** النواة مكتوبة بـ Python 3.12+، ولكنها تدير مشاريع بأي Stack (Laravel, Flutter, .NET, React, إلخ) دون فرض أي تقنية عليها.
3. **المعمارية الأساسية:** Hexagonal Architecture (Ports & Adapters) مفصولة إلى 14 وحدة منطقية واضحة.
4. **الواجهة:** CLI-first مبني على Python، ولا توجد Dashboard أو Web UI أو API في Phase 1.
5. **الإعدادات والذاكرة:** YAML للإعدادات، Markdown + SQLite للذاكرة والوثائق. لا توجد Vector DB في المراحل الأولى.
6. **فصل فئات التكاملات:** فصل حاسم بين Native Model Providers (7)، و Model Gateways (2)، و Coding Tools (6)، و Spec Frameworks (3).
7. **إدارة النماذج والتكلفة:** الجودة أولًا ثم الأقل تكلفة التي تحقق الغرض. تفضيل المحلي والمجاني فقط عند استيفاء متطلبات المهمة. السلوك الافتراضي للميزانية: تحذير ثم منع التشغيل عند التجاوز.
8. **استقلال المزودين:** لا مزود ذكاء اصطناعي شرط لتشغيل النواة؛ توفير Mock Provider للاختبارات التعاقدية دون شبكة أو مفاتيح.
9. **حظر التقنيات المبكرة:** لا Docker كشرط للنواة، لا Kubernetes، لا Kafka، لا Microservices.
10. **خارطة الطريق:** تثبيت المراحل الست دون تغيير ترتيبها، مع مرحلة سابعة منفصلة (Final Audit).
11. **الأمان والعزل:** عزل بيانات وأسرار المشاريع الأخرى تمامًا وعدم الاقتراب منها.
